# Создание файлов описания задачи

## Источник задачи

Описание задачи необходимо получить из каталога [docs/Tasks](../../../docs/Tasks/).
Например задача 0001 будет лежать в файле [docs/Tasks/00001.init.md](../../../docs/Tasks/00001.init.md)

## Создаваемые файлы

### Файл технического задания

Файл технического задания необходим для сохранения исходного текста задачи, если
задача в `.init.md` окажется по какой-то причине недоступна.

Так же такие файлы служат источником примеров решения подобных задач.

#### Расположение

Создаётся в каталоге [docs/Tasks/](../../../docs/Tasks/).

Формат имени {Номер задачи}.tz.md, например
[`docs/Tasks/00001.tz.md`](../../../docs/Tasks/0001.tz.md)


#### Состав

Заголовок задачи из `.init.md` записывается в заголовок файла

Описание задачи из `.init.md` записывается в тело файла

#### Пример файла

- [`docs/Tasks/0001.tz.md`](../../../docs/Tasks/0001.tz.md)

### Файл промпта

Файл необходим для составления подробного плана работ по задаче.

#### Расположение

Создаётся в каталоге [docs/Tasks/](../../../docs/Tasks/).

Формат имени {Номер задачи}.md, например [`docs/Tasks/0001.md`](../../../docs/Tasks/0001.md)

#### Состав

- `Заголовок файла` - совпадает с заголовком задачи `.init.md`
- `Контекст` - кратко описывает бизнес логику и причины, побудившие к созданию задачи. 
    Содержит ответ на вопрос "какую ценность для бизнеса несёт задача" или 
- `Цель` -  содержит ответ на вопрос "какую цель задача преследует" или 
    "какой результат ожидается". Содержит в себе ссылку на файл технического 
    задания с расширением `.tz.md` в том же каталоге
- `Используемые навыки` - набор ссылок на файлы, содержащие правила, спецификации 
    и порядов выполнения подобных задач. Файлы располагаются в каталоге
    [`docs/Specs/)`](../../../docs/Specs/). Необходимо обязательно поискать 
    файлы промптов похожих задач и позаимствовать необходимые навыки оттуда.
- `Дополнительные требования` - уточнения по задаче, которые не содержатся в исползуемых 
    навыков, но необходимы для разъяснения деталей выполнения задачи
- `Похожие задачи` - ссылки на задачи, с походими целями, служащие примером
- `Критерии приёмки` - список случаев, которые должен покрывать написанный код и
    граничные условия.
- `Зависимости и ссылки`:
    + `Задача` - номер этой задачи в, например `0001`
    + `Связанная задача` - из задачи в `.init.md` и тип связи

#### Пример файла
