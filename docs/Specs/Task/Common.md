# Общие требования по решению задач

## Отчет о работе 

В каталоге [`docs/Agents/Tasks/`](../Tasks/) необходимо создать файл, с кратким
изложением того, что было сделано в рамках решения задачи.

Например для задачи `0001` файл `docs/Tasks/0001.todo.md` с содержимым:

```markdown
# Выполнение задачи 0001 "Глобальные настройки для включения/выключения интеграций для определённых сервисов"

Готово. Создано:

1. **Миграция** — `app/database/migrations/2026_04_23_221000_add_performance_separated_details_variables.php`
   - Добавляет 21 глобальную настройку `OPT_PERFOMANCE_SEPARATED_*` типа boolean со значением `"1"` (по умолчанию включены)
   - Все настройки видимы в CMS, не являются настройками витрины
   - `down()` удаляет все созданные записи

2. **Документация** — добавлены строки с описанием всех новых настроек после `OPT_PERFOMANCE_SEPARATED`
```

## Уточненяющие вопросы

Если во время планирования, выполнения плана или в процессе работы были заданы
уточняющие вопросы и на них били даны ответа, то в конце файла задачи необходимо
добавить раздел `Уточняющие вопросы, ответы на них и дополнительные инструкции`

Добавлять вопросы, ответы и инструкции надо сразу после добавления их в чат.
Делать это надо даже в режиме планирования.

Пример:

Номер задачи: 0001

Файл задачи : `docs/Tasks/0001.md` 

```markdown

## Уточняющие вопросы, ответы на них и дополнительные инструкции

### Имя feature-flag

**Вопрос**: Какое имя feature-flag для сущности `просмотр транзакций пользователя`

**Ответ**: table/billing

```
