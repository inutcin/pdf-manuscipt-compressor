# Планирование выполнения задачи 

Необходимо создать подробный план реализации задачи

## Создаваемые файлы

### Файл плана реализации 

Файл необходим исполнителю как подробная инструкция по реализации задачи.

Так же такие файлы служат источником примеров решения подобных задач.

Для составления плана необходимо прочитать промпт задачи в каталоге
[docs/Tasks/](../../../docs/Tasks/). Например промпт задачи `0001` лежит в
файле 
[`docs/Tasks/0001.md`](../../../docs/Tasks/0001.md)

При составлении плана найти и принять за образец ранее составленные планы на
реализацию похожих задач

При составлении плана необходимо проанализировать и учесть содержимое `*.todo.md`
файлов для похожих задач.

Если файла промпта задачи нет, то необходимо остановить составление плана
реализации задачи

#### Расположение

Создаётся в каталоге [docs/Tasks/](../../../docs/Tasks/).

Формат имени {Номер задачи}.plan.md, например
[`docs/Tasks/0001.plan.md`](../../../docs/Tasks/0001.plan.md)

#### Состав

В файл плана необходимо записать все решения, принятые в целях реализации задачи

#### Пример файла

- [`docs/Tasks/MP-12071.plan.md`](../../../docs/Tasks/0001.plan.md)
