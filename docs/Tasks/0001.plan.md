# План реализации задачи 0001 «Создание cli скрипта для сжатия pdf-документа рукописных лекций»

Промпт задачи: [`docs/Tasks/0001.md`](./0001.md)
Техническое задание: [`docs/Tasks/0001.tz.md`](./0001.tz.md)

## Цель

Автоматизировать ручной способ конвертации (pdf → pbm → pdf → сборка) в виде
cli-скрипта `pdfmanuc`, а также документировать установку и использование в
корневом `README.md`.

## Ожидаемый результат

1. `cli/pdfmanuc` — исполняемый bash-скрипт в корне проекта.
2. `README.md` — документация на английском языке в корне проекта.
3. `docs/ARCHITECTURE.md` — актуализированная структура проекта и описание
   добавляемого компонента `cli/pdfmanuc`.

## Исходные данные и ограничения

- Все комментарии в коде — на русском языке
  ([`docs/Specs/Code/Common.md`](../Specs/Code/Common.md)).
- Манипуляции с git не выполняются.
- При добавлении каталогов структура в [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md)
  актуализируется. В разделе «Структура проекта» перечисляются **только
  каталоги** (без файлов); описание добавляемого компонента приводится в
  разделах «Компоненты и их взаимодействие» и «Описание компонентов».
- Эталонный пример сжатия: `core.pdf` (14.2M) → `core.compressed.pdf` (149K),
  описан в ТЗ.

## Принятые решения

1. **Имя скрипта** — строго `pdfmanuc` (pdf manuscript compressor). В ТЗ в
   примере минимального запуска встречается опечатка `pdfmanc`; используем
   вариант из требований и критериев приёмки — `pdfmanuc`.
2. **Расширение результата** — `.manuc.pdf`. В ручном примере ТЗ результат
   называется `core.compressed.pdf`; согласно требованиям и критериям приёмки
   используем `core.manuc.pdf`.
3. **Язык реализации** — `bash` (соответствует AGENTS.md проекта):
   `#!/usr/bin/env bash`, `set -euo pipefail`.
4. **Интерфейс командной строки**:
   - `pdfmanuc <входной.pdf>` — минимальный запуск;
   - `-h`, `--help` — справка по использованию;
   - `-o <файл>` — выходной файл; по умолчанию `<входной>.manuc.pdf` в каталоге
     исходного файла;
   - `-r <разрешение>` — целевое разрешение в DPI, по умолчанию `300`.
   - Неизвестные аргументы и отсутствие входного файла — сообщение об ошибке и
     выход с ненулевым кодом.
5. **Исходный файл не удаляется** — результат размещается рядом с исходным.
6. **Проверка зависимостей** — при старте проверяется наличие `pdftoppm`,
   `img2pdf`, `pdftk`. При отсутствии хотя бы одной утилиты печатается короткая
   справка по установке (Ubuntu, Red Hat, Arch), согласованная с разделом
   «Installation» корневого `README.md`, и выполняется `exit 1`.
7. **Промежуточные файлы** — создаются в каталоге `mktemp -d` и удаляются по
   завершении через `trap 'rm -rf "$tmpdir"' EXIT` (в том числе при ошибке).
8. **Конвейер обработки**:
   - `pdftoppm -r <разрешение> -mono <входной> <tmp>/page`;
   - для каждого `*.pbm` — `img2pdf <page>.pbm -o <page>.pdf`;
   - `pdftk <page>.pdf ... cat output <выходной>`.
9. **README.md** — на английском языке, разделы:
   - «About» — назначение проекта и краткое описание;
   - «Installation» — клонирование репозитория; установка `pdftoppm`/`img2pdf`/
     `pdftk` для Ubuntu, Red Hat, Arch; размещение скрипта в пользовательский и
     системный исполняемый каталог;
   - «Quick start» — простейший пример `pdfmanuc core.pdf`;
   - «Advanced usage» — все атрибуты командной строки с примерами.

## Порядок выполнения

1. Создать каталог `cli/` в корне проекта.
2. Создать `cli/pdfmanuc` с разбором аргументов, проверкой зависимостей,
   конвейером конвертации и очисткой временного каталога.
3. Выдать скрипту право на выполнение (`chmod +x cli/pdfmanuc`).
4. Создать `README.md` на английском языке с разделами «About», «Installation»,
   «Quick start», «Advanced usage»; текст установки и справки об ошибке
   синхронизировать.
5. Актуализировать `docs/ARCHITECTURE.md`: дополнить раздел «Структура проекта»
   (только каталоги) каталогом `cli/`, добавить схему взаимодействия компонентов
   и описание `cli/pdfmanuc` и используемых утилит.
6. Провести ручную проверку на эталонных файлах из ТЗ.
7. Создать отчёт `docs/Tasks/0001.todo.md` по
   [`docs/Specs/Task/Common.md`](../Specs/Task/Common.md).

## Проверка результата

- `cli/pdfmanuc -h` печатает справку.
- `cli/pdfmanuc core.pdf` создаёт `core.manuc.pdf` рядом с исходным, исходный
  файл остаётся на месте.
- `cli/pdfmanuc -o out.pdf core.pdf` создаёт `out.pdf`.
- `cli/pdfmanuc -r 600 core.pdf` использует указанное разрешение.
- При удалённой зависимости скрипт печатает справку по установке и завершается
  с ошибкой.
- После выполнения во временном каталоге не остаётся промежуточных файлов.
