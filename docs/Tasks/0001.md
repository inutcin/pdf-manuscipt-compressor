# Создание cli скрипта для сжатия pdf-документа рукописных лекций

## Контекст

Встроенное ПО планшета, используемого для записи лекций, создаёт pdf-файлы
очень больших размеров. При этом внутри находятся черно-белые изображения
небольшой плотности (более 99% площади — белый фон). Бизнес-ценность задачи —
получить инструмент, который кратно уменьшает размер исходных файлов без
существенной потери читаемости при просмотре с экрана планшета или компьютера.

## Цель

Автоматизировать ручной способ конвертации (pdf → pbm → pdf → сборка) в виде
cli-скрипта `pdfmanuc`, а также документировать установку и использование в
корневом `README.md`.

Исходный текст задачи: [`docs/Tasks/0001.tz.md`](./0001.tz.md)

## Дополнительные требования

1. Скрипт должен проверять наличие необходимого ПО и при отсутствии печатать
   короткую справку об установке для различных операционных систем из раздела
   "Установка" корневого `README.md`.
2. Промежуточные файлы размещаются во временном каталоге и удаляются после
   выполнения скрипта.
3. Скрипт `pdfmanuc` размещается в каталоге `cli/` в корне проекта.
4. `README.md` пишется на английском языке.
