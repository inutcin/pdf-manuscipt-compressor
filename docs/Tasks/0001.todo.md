# Выполнение задачи 0001 «Создание cli скрипта для сжатия pdf-документа рукописных лекций»

Готово. Создано и изменено:

1. **`cli/pdfmanuc`** — исполняемый bash-скрипт (`chmod +x`), автоматизирующий
   ручной конвейер `pdf → pbm → pdf → сборка`:
   - зависимости: `#!/usr/bin/env bash`, `set -euo pipefail`;
   - аргументы: `<входной.pdf>`, `-h`/`--help`, `-o <файл>`, `-r <разрешение>`
     (по умолчанию `300`);
   - выходной файл по умолчанию — `<входной>.manuc.pdf` рядом с исходным,
     исходный файл не удаляется;
   - проверка наличия `pdftoppm`, `img2pdf`, `pdftk`; при отсутствии печатается
     справка по установке (Ubuntu, Red Hat, Arch) и выполняется `exit 1`;
   - промежуточные файлы создаются в `mktemp -d` и удаляются через
     `trap 'rm -rf "$tmpdir"' EXIT`, в том числе при ошибке;
   - конвейер: `pdftoppm -r <res> -mono` → `img2pdf` для каждого `*.pbm` →
     `pdftk ... cat output <выходной>`.

2. **`README.md`** — документация на английском языке с разделами «About»,
   «Installation» (клонирование, зависимости для Ubuntu/Red Hat/Arch, установка
   скрипта в пользовательский и системный каталог), «Quick start»,
   «Advanced usage» (все аргументы с примерами).

3. **`docs/ARCHITECTURE.md`** — актуализирован: в разделе «Структура проекта»
   перечислены только каталоги, добавлены схема взаимодействия компонентов и
   описание компонента `cli/pdfmanuc` и используемых утилит.

## Проверка результата

- `cli/pdfmanuc -h` — печатает справку, код возврата `0`.
- `cli/pdfmanuc` без аргументов — сообщение об ошибке, код возврата `1`.
- `cli/pdfmanuc --bad-option` — сообщение о неизвестном аргументе, код возврата `1`.
- `cli/pdfmanuc /nonexistent.pdf` — сообщение об отсутствии файла, код возврата `1`.
- `cli/pdfmanuc -o /tmp/core.manuc.test.pdf docs/pdf/examples/core.pdf` —
  создан файл `149054` байт (эталон `core.compressed.pdf` — `149103` байт),
  промежуточные `page-*` во временном каталоге не остались.
