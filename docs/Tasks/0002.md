# Уровни сжатия

## Контекст

Скрипт `pdfmanuc` сжимает pdf-документы рукописных лекций по конвейеру
pdf → монохромные pbm → постраничные pdf → сборка. Сейчас разрешение задаётся
произвольным значением `-r`, а цветовой режим жёстко зафиксирован как
монохромный. При этом целевые устройства предъявляют разные требования:
электронные чернила (eink) не нуждаются в высоком разрешении, планшету нужен
монохром с большим разрешением, а для печати необходимы градации серого.
Бизнес-ценность задачи — получить единый инструмент с готовыми профилями под
устройство, без ручного подбора разрешения и режима.

## Цель

Добавить в cli-скрипт `pdfmanuc` атрибут `--for-device` с профилями `eink`,
`tablet`, `print`, задающими разрешение и цветовой режим, и обновить корневой
`README.md`.

Исходный текст задачи: [`docs/Tasks/0002.tz.md`](./0002.tz.md)

## Дополнительные требования

1. Атрибут `--for-device` задаёт пресет разрешения и цветового режима; если
   атрибут не указан, применяется профиль `tablet`.
2. Профили:
   - `eink` — разрешение `150` dpi, монохромный режим;
   - `tablet` — разрешение `300` dpi, монохромный режим;
   - `print` — разрешение `300` dpi, градации серого.
3. Монохромные профили (`eink`, `tablet`) конвертируются через
   `pdftoppm -mono`, профиль `print` — через `pdftoppm -gray`.
4. Существующий атрибут `-r <разрешение>` сохраняется и при явном указании
   переопределяет разрешение выбранного профиля.
5. Отдельный атрибут цветового режима (например `--color`) не вводится —
   режим определяется только профилем.
6. Корневой `README.md` ведётся на английском языке (как в задаче `0001`);
   добавляется описание уровней сжатия и атрибута `--for-device`.

## Уточняющие вопросы, ответы на них и дополнительные инструкции

### Взаимодействие `--for-device` и `-r`

**Вопрос**: Как атрибут `--for-device` должен взаимодействовать с уже
существующим `-r <разрешение>` в `cli/pdfmanuc`?

**Ответ**: `--for-device` задаёт пресет (разрешение и цветовой режим), а явный
`-r` переопределяет разрешение выбранного профиля. Обратная совместимость
сохраняется.

### Отдельный атрибут цветового режима

**Вопрос**: Нужно ли для профиля `print` (градации серого) вводить отдельный
атрибут режима, например `--color`?

**Ответ**: Нет. Режим определяется только профилем: `print` использует
`pdftoppm -gray`, профили `eink` и `tablet` — `pdftoppm -mono`.
