# Уровни сжатия

1. Необходимо предусмотреть атрибут командной строки `--for-device`
- `eink` для экранов eink
    + Разрешение 150dpi
    + Цветовой режим - монохромный
- `tablet` для планшета
    + Разрешение 300dpi
    + Цветовой режим - модохромный
- `print` для печати
    + Разрешение 300dpi
    + Цветовой режим - градации серого

2. Если атрибут не задан, то по умолчанию используется `tablet`

3. Необходимо внести изменения в документацию в README.md
