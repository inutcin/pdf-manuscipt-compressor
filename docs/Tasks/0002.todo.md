# Выполнение задачи 0002 «Уровни сжатия»

Готово. Создано и изменено:

1. **`cli/pdfmanuc`** — добавлен атрибут `--for-device` с профилями
   устройства:
   - `eink` — разрешение `150` dpi, режим `pdftoppm -mono`;
   - `tablet` — разрешение `300` dpi, режим `pdftoppm -mono` (профиль по
     умолчанию);
   - `print` — разрешение `300` dpi, режим `pdftoppm -gray`.
   - Явный `-r <разрешение>` переопределяет разрешение выбранного профиля;
     цветовой режим всегда определяется профилем.
   - Добавлена валидация значения `--for-device`; справка `usage` обновлена.
   - Расширение файлов страниц выбирается по режиму: `-mono` → `*.pbm`,
     `-gray` → `*.pgm` (исправлен баг, найденный при проверке: `pdftoppm -gray`
     создаёт `.pgm`, из-за чего профиль `print` ранее не собирался).

2. **`README.md`** — добавлен раздел «Compression levels» с таблицей профилей
   (`eink`/`tablet`/`print`) и описание атрибута `--for-device` в разделе
   «Advanced usage» с примерами.

3. **`docs/Tasks/0002.plan.md`** — создан план реализации по
   [`docs/Specs/Task/plan.md`](../Specs/Task/plan.md).

## Проверка результата

Проверено на эталонном `docs/pdf/examples/core.pdf` (11 страниц, 14 557 446 байт):

- `cli/pdfmanuc -h` — код возврата `0`, справка содержит `--for-device`,
  `eink`, `tablet`, `print`.
- `cli/pdfmanuc --for-device eink -o /tmp/pd2_eink2.pdf core.pdf` — код `0`,
  размер `77 986` байт, ширина страницы `767` px (~150 dpi).
- `cli/pdfmanuc --for-device print -o /tmp/pd2_print2.pdf core.pdf` — код `0`,
  размер `1 319 087` байт; `pdfimages -list` показывает `color=gray` (градации
  серого), `pdfinfo` — 11 страниц.
- `cli/pdfmanuc -o /tmp/pd2_default2.pdf core.pdf` — код `0` (профиль `tablet`
  по умолчанию), размер `149 124` байт.
- `cli/pdfmanuc --for-device tablet -r 600 -o /tmp/pd2_r600_2.pdf core.pdf` —
  код `0`, разрешение переопределено на `600` dpi, размер `294 875` байт.
- `cli/pdfmanuc --for-device unknown ...` — код `1`, сообщение о недопустимом
  профиле устройства.
- `cli/pdfmanuc --for-device` (без значения) — код `1`, сообщение о
  необходимом значении.
- `cli/pdfmanuc` (без входного файла) — код `1`, сообщение об отсутствии
  входного файла.
- `cli/pdfmanuc --for-device eink -r 0 core.pdf` — код `1`, сообщение о
  недопустимом разрешении.
- Промежуточные файлы `page-*` в рабочем каталоге не остаются (используется
  `mktemp -d` и `trap ... EXIT`).
